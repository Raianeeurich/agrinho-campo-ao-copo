🌾 Agronegócio Sustentável: Cultivando o Futuro sem Esgotar a Terra
Projeto desenvolvido para o Concurso Agrinho 2026 – Categoria Programação
Subcategoria 3: Programação Front-End – HTML, CSS e JavaScript.

🌱 Tema do Concurso
Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente.

📌 Sobre o Projeto
O projeto “Agronegócio Sustentável: Cultivando o Futuro sem Esgotar a Terra” é uma plataforma web interativa desenvolvida para conscientizar e educar a sociedade sobre a possibilidade e a necessidade de produzir em harmonia com a natureza.

Por meio de textos objetivos, imagens imersivas, um quiz dinâmico, curiosidades sobre o campo, um vídeo explicativo e uma história em quadrinhos, o site busca aproximar o visitante da realidade do campo. O projeto demonstra como práticas inovadoras de conservação do solo, rotação de culturas e o uso consciente da água conseguem manter o agro forte e produtivo, sem esgotar as riquezas naturais do nosso planeta.

🎯 Objetivo
O objetivo do projeto é explicar, de maneira simples e interativa, como a produção moderna pode e deve ser feita de forma responsável, quebrando o mito de que o agronegócio e a preservação ambiental são caminhos opostos.

O site detalha como os ciclos produtivos do campo (como o plantio e o manejo) envolvem planejamento, tecnologia de precisão, pessoas qualificadas e o respeito à biodiversidade local, gerando impactos positivos e sustentáveis para toda a sociedade.

🧭 Funcionalidades do Site
O projeto conta com as seguintes funcionalidades:

🏠 Página inicial com apresentação do tema;
📱 Menu de navigation responsivo para fácil navegação;
🌾 Seção explicativa detalhando como cultivar sem esgotar a terra;
♿ Botão de acessibilidade integrado de forma limpa;
🔠 Opção de aumentar e diminuir a fonte para melhor leitura;
🌓 Modo de alto contraste para acessibilidade visual;
📲 Layout adaptado para diferentes tamanhos de tela (responsivo).
💻 Tecnologias Utilizadas
O projeto foi desenvolvido utilizando apenas tecnologias básicas de front-end:

HTML5: Estruturação semântica de todo o conteúdo do site.

CSS3: Estilização, definição de cores, tipografia e responsividade.

JavaScript: Manipulação do DOM para os botões de acessibilidade, modo escuro/contraste e a lógica do quiz.

✅ Os arquivos de estilo e script estão separados e corretamente declarados.

🌿 Sustentabilidade
O conteúdo do site aborda práticas essenciais relacionadas ao equilíbrio entre produção e meio ambiente, como:

🌱 Conservação e Regeneração do Solo: Práticas de plantio direto que mantém o solo vivo e rico em nutrientes.
🚜 Tecnologia Poupa-Terra: Como a agricultura de precisão aumenta a produtividade na mesma área, evitando novos desmatamentos.
💧 Gestão Inteligente da Água: Uso de dados e sensores para evitar o desperdício em sistemas de irrigação.
🧠 Conceitos de Programação Aplicados
Durante o desenvolvimento do projeto, foram aplicados conceitos importantes de programação front-end, como:

Estruturação semântica com HTML;

Estilização com CSS externo e uso de variáveis CSS para controle de cores;

Responsividade com media queries;

Manipulação do DOM com JavaScript para o menu de acessibilidade (controle de fonte e contraste).

🤖 Prompts de IA Utilizados para as Imagens
🌾 Imagem Campo de cultivo
Crie uma imagem realista e educativa de um campo agrícola sustentável em Guarapuava, no Paraná, com atmosfera acolhedora, luz natural suave, paisagem bem cuidada, céu limpo e sensação de conexão entre produção rural, sustentabilidade e futuro. A imagem deve transmitir equilíbrio entre o agro forte e o cuidado com o meio ambiente.

🌱 Imagem Campo — Cultivo e Solo
Crie uma imagem de uma lavoura em fase de crescimento saudável, mostrando o cuidado com o solo fértil e vivo e a importância da agricultura sustentável. A cena deve ter cores naturais, aparência limpa, clima positivo e representar o início da cadeia de alimentos responsável.

Todos os recursos foram aplicados com finalidade puramente educacional, respeitando o tema do concurso para tornar o aprendizado mais visual, acessível e interativo.
